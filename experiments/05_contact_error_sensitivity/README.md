# 05 接触误差对下游的敏感性（A3）：回答 CVPR 审稿人 7TmV

日期：2026-10-28。

## 问题

CVPR 审稿人 7TmV 问过：接触估计的准确性如何，出错时对后续模块有什么影响？本实验回答三个问题：
- 接触判断的时刻偏差和抖动，分别会让物体误差和 HOI 误差增加多少；
- 真实 VC 离"完美接触"还有多远；
- 我们的 OT（闭式融合 + IMU 静止门）和原版 IMUHOI 的 OT，在接触出错时谁退化得更多。

## 设置

**两条管线**：IMUHOI++（VC-v5ar + OT-v2_armrot_biclose）和原版三分支 IMUHOI，都用原生 7/3 协议，测试集，seed 42。

**扰动方式**：在线推理时，把 VC 输出的三路接触（左手、右手、物体运动）替换成 GT 接触，再加两类扰动之一：
- **时刻平移**：GT 整体平移 K ∈ {−15, −10, −5, +5, +10, +15} 帧。正数表示判断偏晚。
- **抖动**：每条序列的每个通道随机反转 3–10 帧的片段，名义翻转比例 5% / 10% / 20%。实际翻转比例因片段重叠略低，为 4.8–5.0% / 9.3–9.6% / 18.0–18.2%。

**配对**：随机种子只由序列文件名和通道决定，两条管线收到完全相同的扰动，翻转帧数逐一相同。

**参照**：
- 误差增量是相对"精确 GT 接触"的变化，逐序列计算后取平均。区间按序列 bootstrap，两条管线的比较是配对的。
- 每条管线自己的真实 VC 作为参考线。

**校验**：GT 替换后，发布的接触 F1 正好为 1.0。

## 结果

### 1. 真实 VC 离完美接触还有多远

| 管线 | OMOMO 物体 / HOI | BEHAVE 物体 / HOI |
|---|---|---|
| IMUHOI++：真实 VC 减 GT 接触 | +0.43 / +0.32 cm | +1.58 / +1.70 cm |
| IMUHOI 原版：真实 VC 减 GT 接触 | −0.28 / +0.21 cm | +23.3 / +53.5 cm |

- 对我们的管线，接触已经不是主要误差来源：换成完美接触，OMOMO 只少 0.3–0.4 cm，BEHAVE 只少 1.6–1.7 cm。
- 原版 IMUHOI 在 BEHAVE 上的 HOI 误差为 79.9 cm，换成完美接触后降到 26.4 cm。也就是说，它的 HOI 误差大头来自接触估计。
- 用抖动曲线线性插值做个粗略换算：我们真实 VC 的下游代价，相当于 OMOMO 上 0.7–1.6%、BEHAVE 上 2.5–4.8% 的翻转。

### 2. 时刻误差：±5 帧几乎无影响；两条管线怕的方向不同

**我们的管线**（物体 / HOI 误差增量）：

| 平移 | OMOMO | BEHAVE |
|---|---|---|
| ±5 帧 | 最多 +0.3 cm | 最多 +0.3 cm |
| ±10 帧 | 物体最多 +1.1，HOI 最多 +0.7 | 同左 |
| 提前 15 帧 | +2.9 / +1.5 | +0.8 / +0.9 |
| 偏晚 15 帧 | +2.1 / +0.9 | +1.8 / +1.1 |

**与原版的配对比较**（我们的退化减原版的退化，负数表示我们更稳）：

| 情况 | 物体 | HOI |
|---|---|---|
| OMOMO 提前 10 帧 | −1.61 [−1.88, −1.32] | −2.34 [−2.58, −2.09] |
| OMOMO 提前 15 帧 | −1.68 | −3.75 |
| OMOMO 偏晚 5–15 帧 | +0.4 到 +1.7 | +0.6 到 +1.2 |
| BEHAVE 偏晚 5 帧（HOI） | | −1.6 [−2.9, −0.6] |
| BEHAVE 偏晚 10 帧（HOI） | | −3.3 [−6.1, −1.2] |
| BEHAVE 偏晚 15 帧（HOI） | | −5.4 [−9.7, −2.2] |

- **OMOMO 上接触提前**：我们的退化明显更小。以提前 10 帧为例，物体误差 +1.05 对 +2.66，HOI +0.68 对 +3.02。
  可能的原因是 IMU 静止门：物体静止时，无论接触怎么判断，位置都被钉在原地，所以提前判出的接触不会把物体提前拉向手。这是推测，没有单独做消融。
- **OMOMO 上接触偏晚**：我们的退化略多，因为原版在偏晚时误差反而略降。
- **BEHAVE 上接触偏晚**：原版的 HOI 明显变差（+1.6 / +3.8 / +6.4），我们几乎不变（+0.0 / +0.5 / +1.1）。接触提前时两者没有差别。

### 3. 抖动才是我们闭式融合的主要风险

我们的管线在不同翻转比例下的误差增量：

| 翻转比例 | OMOMO 物体 | OMOMO HOI | BEHAVE 物体 | BEHAVE HOI |
|---|---|---|---|---|
| 5% | +3.3 | +1.0 | +3.1 | +1.8 |
| 10% | +4.7 | +1.9 | +4.9 | +2.7 |
| 20% | +7.0 | +3.7 | +6.6 | +5.1 |

与原版比较：
- **OMOMO**：两条管线退化几乎一样，配对差值都不显著。
- **BEHAVE 的 HOI**：我们退化得更多，配对差值 +1.6 / +2.1 / +3.2 cm，都显著。
- **BEHAVE 的物体误差**：原版在抖动下反而下降 22–26 cm。这是假象：三分支没有静止候选，非接触时段完全靠 IMU 积分，一路漂移；插入的假接触让物体短暂吸附到手附近，等于意外地重置了漂移。所以这条曲线不能当作抗干扰能力的比较。

**解读**：闭式融合更直接地信任接触信号，接触准时能充分利用 FK，接触抖动时就会受伤。所以 A1 里我们 VC 的假切换大约少一半，是这个 OT 设计能成立的前提，两者应作为一个整体来理解。

## 对论文的影响

可以写的：
- 对审稿人问题的直接回答：有了我们的 VC，接触误差的下游代价已经很小。换成完美接触，OMOMO 只改善 0.4 / 0.3 cm，BEHAVE 只改善 1.6 / 1.7 cm。对原版 IMUHOI，BEHAVE 上完美接触能去掉 80 cm HOI 误差中的 53 cm。
- 起止时刻 ±5 帧的误差几乎没有影响。我们的 OT 对 OMOMO 上的接触提前、BEHAVE 上的接触偏晚，比原版稳得多。
- 抖动是闭式融合的关键失败模式，这说明降低 VC 的抖动是必要的，与 A1 的结论相互支撑。
- 图：`omomo/contact_sensitivity.png`、`behave/contact_sensitivity.png`。

不要写的：
- 笼统地说"我们的融合在接触出错时退化更平缓"。抖动下并非如此：BEHAVE 的 HOI 我们退化更多，OMOMO 两者持平。
- 用原版在 BEHAVE 上抖动时物体误差下降的曲线做任何鲁棒性论证。

## 局限

- 单 seed、单 checkpoint；只用测试集。
- 替换进去的 GT 接触是 0/1 硬值，而真实 VC 输出的是软概率。真实误差是时刻偏差、抖动和不确定性的混合，这里分开模拟，是一种理想化。
- 平移对三路接触同时生效、对所有事件一致；真实的时刻误差是逐事件的。
- 静止门等机制解释没有单独消融。
- 没有包含带静止候选的四候选 IMUHOI。要比较"不漂移前提下的鲁棒性"，它才是更合适的对照；三分支在 BEHAVE 上的物体误差由漂移主导。
