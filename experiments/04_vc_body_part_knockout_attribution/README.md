# 04 身体部位剔除与归因（A2）：VC 是否真的在用姿态先验，用的是哪里、哪段时间

日期：2026-10-28。对应创新点 1（HP 姿态先验作为 VC 输入）。

## 问题

- 训练好的 IMUHOI++ VC 在做接触判断时，是否真的依赖 HP 给出的人体姿态？依赖哪个身体部位？
- 每只手的接触是否主要由同侧手臂决定？这是一个物理常识层面的 sanity check。
- 判断依据在时间上分布在哪里：接触起点之前，还是起止前后？
- 推/拖和搬起两种交互方式下，各部位的权重是否不同？

## 设置

**模型**：OMOMO 和 BEHAVE 上的 IMUHOI++ 最优管线（VC-v5ar + OT-v2_armrot_biclose），原生 7/3 协议，测试集，seed 42。

**参考运行**：
- 与存档评测逐位一致。
- 同时统计 VC 每一路姿态输入在所有前向调用上的均值，作为剔除和归因的基线。

**剔除**：在线推理时把某路输入替换成均值，六种条件如下。

| 条件 | 替换内容 |
|---|---|
| left arm / right arm / torso / both legs | 对应部位编码器的输入。只切断姿态先验通路，掌心速度和 coupling 特征保留 |
| all groups (b_t) | 整个边界特征 b_t，五个部位一起去掉 |
| all HP inputs | b_t，加上掌心速度和加速度，加上由掌心位置算出的三个 coupling 信号（双手间距、间距变化率、掌心相对速度）。VC 收不到任何 HP 信息 |

指标：每只手的帧级 F1、起点和终点事件 F1（容差 10 帧，只统计滑动窗口区域的事件，与 A1 相同）、物体和 HOI 误差。置信区间按序列做配对 bootstrap。

**积分梯度（IG）**：
- 在线推理时捕获每个 GT 手接触起止帧所在发布窗口的完整 VC 输入。冒烟测试中，用捕获的输入重算出的概率与发布值在 1e-4 内一致。
- 目标是该帧发布的手接触概率，对五个部位编码器的输入求归因：基线为均值，64 步积分。
- 每个窗口把 |IG| 归一化，得到部位占比和时间分布。
- 排除两类窗口：
  - 姿态通路整体只改变概率不到 0.05 的：OMOMO 144 个，BEHAVE 195 个；
  - IG 之和与概率变化相差超过 10%、积分没收敛的：OMOMO 5 个，BEHAVE 24 个。
- 最终使用 OMOMO 536 个、BEHAVE 434 个窗口。

## 结果

### 1. 同侧手臂主导对应手的接触（sanity check 成立）

剔除一侧手臂后，同侧手下降幅度减去对侧手下降幅度（95% CI）：

| 数据集 | 剔除 | 帧级 F1 | 起点事件 F1 | 终点事件 F1 |
|---|---|---|---|---|
| OMOMO | 左臂 | −0.088 [−0.100, −0.077] | −0.217 [−0.298, −0.134] | −0.235 [−0.283, −0.188] |
| OMOMO | 右臂 | −0.042 [−0.050, −0.035] | −0.183 [−0.268, −0.107] | −0.197 [−0.240, −0.149] |
| BEHAVE | 左臂 | −0.047 [−0.070, −0.025] | −0.065 [−0.125, −0.019] | −0.083 [−0.156, −0.026] |
| BEHAVE | 右臂 | −0.032 [−0.063, −0.006] | −0.062 [−0.107, −0.020] | −0.087 [−0.140, −0.028] |

- 在 OMOMO 上，剔除左臂后左手帧级 F1 降 0.098，右手只降 0.010；左手的起止事件 F1 降 0.25 左右，右手没有显著变化。
- BEHAVE 上方向相同但较弱，对侧手也会下降。

### 2. 姿态先验被大量依赖，两个数据集都是如此

| 剔除 | OMOMO 帧级 F1 左 / 右 | OMOMO Object / HOI | BEHAVE 帧级 F1 左 / 右 | BEHAVE Object / HOI |
|---|---|---|---|---|
| 左臂 | −0.098 / −0.010 | +1.6 / +1.2 cm | −0.086 / −0.039 | +1.6 / +1.8 cm |
| 右臂 | −0.009 / −0.051 | +2.6 / +1.3 | −0.039 / −0.071 | +1.2 / +1.3 |
| 躯干 | −0.005 / −0.007 | +0.3 / +0.1 | −0.004 / −0.011 | +0.4 / +0.1 |
| 双腿 | −0.016 / −0.020 | −0.2 / −0.0 | −0.007 / −0.005 | +1.1 / +0.6 |
| 全部部位（b_t） | −0.199 / −0.086 | +3.0 / +1.5 | −0.079 / −0.090 | +4.8 / +3.5 |
| 全部 HP 输入 | −0.404 / −0.180 | +2.3 / +1.8 | −0.095 / −0.126 | +5.4 / +4.6 |

参考值：OMOMO 物体误差 13.34 cm、HOI 10.48 cm，BEHAVE 分别为 22.93 和 17.19 cm。

- 去掉姿态先验通路后，BEHAVE 的物体误差升到约 27.7 cm，HOI 升到约 20.7 cm，影响比 OMOMO 还大。所以"BEHAVE 上剔除姿态几乎没影响"的担心并不成立。
- 单独剔除躯干或腿的影响很小，信息主要来自手臂。

### 3. 判断依据集中在起止事件前后约 ±10 帧，没有长时间的提前积累

窗口覆盖事件前 59 帧到事件后 10 帧（后 10 帧是前瞻）。|IG| 在各时间段的占比：

| 事件 | 事件帧之前 | 事件前 10 帧以前（窗口还看不到事件） | 事件帧及前瞻（最后 11 帧） |
|---|---|---|---|
| 均匀分布时 | 0.84 | 0.70 | 0.16 |
| OMOMO 起点 | 0.66 | 0.42 | 0.34 |
| OMOMO 终点 | 0.64 | 0.36 | 0.36 |
| BEHAVE 起点 | 0.76 | 0.54 | 0.24 |
| BEHAVE 终点 | 0.69 | 0.44 | 0.31 |

- 归因明显集中在事件附近，并且很大一部分落在能看到事件之后的前瞻帧上。
- 这和 A1"起点没有提前量"、实验 02"接触前读不出交互方式"一致。
- 网络是在事件发生时，结合最近约 10 帧和前瞻帧判断的，而不是提前预测。

### 4. IG 中的左右侧差异比剔除实验弱

同侧手臂减对侧手臂的 |IG| 占比：
- OMOMO：左手起点 +0.069 [+0.049, +0.091]，右手终点 +0.048，左手终点 +0.014，右手起点约 0。
- BEHAVE：+0.010 到 +0.039，左手终点甚至是 −0.031。

IG 衡量的是梯度乘以输入偏离均值的幅度，剔除衡量的是功能上的影响，两者不必一致。作为功能证据，以剔除实验为准。

### 5. 按交互方式：推/拖时腿的占比更高，躯干没有差别

| 数据集 | 部位 | 搬起 | 推/拖 |
|---|---|---|---|
| OMOMO | 左腿 / 右腿 | 0.159 / 0.160 | 0.177 / 0.174 |
| OMOMO | 左臂 / 右臂 | 0.240 / 0.250 | 0.221 / 0.233 |
| BEHAVE | 左腿 / 右腿 | 0.156 / 0.145 | 0.175 / 0.164 |
| BEHAVE | 左臂 | 0.246 | 0.223 |

- 推/拖时腿的占比更高，手臂的占比更低。
- 躯干在两种方式下相同，OMOMO 0.190 对 0.195，BEHAVE 0.192 对 0.187。
- 原先预期的"搬起大物体时躯干和腿的权重上升"不成立。腿在推/拖中更重要，可能和推的过程中持续迈步有关。

## 解读和注意事项

- **剔除测的是依赖，不是收益。** 网络训练时有姿态输入，测试时换成均值属于分布外输入，下降幅度会偏大。
  它证明的是"训练好的 VC 在用姿态"。"有姿态输入比不用它训练的 VC 更好"要靠重训消融；之前的流程级对比（pose-prior VC 对 IMUHOI VC）显示，这个收益在 BEHAVE 上的帧级 F1 几乎为 0（左 +0.008 / 右 −0.002），OMOMO 上为 +0.034。
- **IG 只覆盖部位编码器这一条通路。** 掌心动态和 coupling 特征也来自 HP，但不在归因范围内。
- **IG 的符号依赖基线。** BEHAVE 上实际姿态相对均值姿态往往降低接触概率，平均 Δp 为负。所以只解读占比，不解读正负。

## 对论文的影响

可以写的：
- VC 的接触判断明确依赖姿态先验：去掉姿态通路，OMOMO 和 BEHAVE 的物体误差分别升 3.0 cm 和 4.8 cm。
- 每只手的接触主要由同侧手臂决定，两个数据集上都显著。`*/knockout_effects.png` 适合作为可解释性的 sanity check 图。
- 判断依据集中在接触切换前后约 10 帧。`*/ig_heatmap.png` 可以放补充材料。

不要写的：
- "姿态先验提前预测接触"：归因不集中在事件之前。
- "搬起时躯干和腿更重要"：数据显示的是推/拖时腿更重要。
- 用剔除结果证明姿态先验带来的收益：这需要重训消融。
