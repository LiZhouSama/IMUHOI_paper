# 测试无 mesh 条件下的双手物体位置先验：统计与修正实验

## 结论与输入边界

用户已明确：物体 mesh 最多在训练阶段可用；测试阶段没有 mesh，最多知道物体类别。因此不能直接把测试 mesh 主轴、SDF、最近表面点或点云放入推理流程。上一轮依赖已知 mesh 方向的实验只能说明几何潜力，不能作为这个设置下直接可部署的方法。

本轮有三项主要结论：

1. 一般物体的真实位置确实接近真实双手垂直平分面：排除上一轮细长类后，OMOMO 中位 2.50 cm、93.49% 在 10 cm 内；BEHAVE 中位 2.72 cm、89.27% 在 10 cm 内。
2. 不能由此推断“把预测位置投影到预测双手平面”有益。现有预测已很接近预测平面，但手部误差会将平面移偏；OMOMO 硬投影使整体物体误差和抖动恶化。
3. 本次真正不读取测试 mesh 的探索性重放中，类别条件的共同偏移分布与小幅因果修正比硬投影更合适。训练侧选择的 BEHAVE 方法改善约 0.29 cm 整体物体误差、0.91 cm 双手帧物体误差；OMOMO 没有值得立即集成的稳定且实用的收益。

本报告区分三种条件：

- 无 mesh、无类别：只能用可观测双手、IMU、接触概率和历史。
- 无 mesh、有已见类别：可使用训练期间学到的类别参数，但不能读取该测试样本的几何。
- 未见实例、未知朝向约定：同一个“椅子”类别可能具有不同尺寸、把手和安装方向；本次同一数据集类别结果不构成这种泛化能力的验证。

尤其不能把“已知类别”偷偷解释为“可以按名字加载测试物体 mesh”。本轮修正函数没有 mesh 输入。

## 二、为什么一个正确的真实几何先验可能修坏预测

在本轮测试预测缓存中，仅看一般物体的真实双手帧：

| 距离中位数 | OMOMO | BEHAVE |
|---|---:|---:|
| 真实物体到真实双手平面 | 2.57 cm | 2.98 cm |
| 预测物体到预测双手平面 | 2.82 cm | 3.02 cm |
| 真实物体到预测双手平面 | 5.23 cm | 8.61 cm |

注意这里使用测试缓存公布的帧，因此与上一节全量 train+test 统计略有不同。预测点已经满足大部分平面先验，继续将它拉到预测平面并不等于拉向真实物体。

这也不是纯粹因为先验“太弱”：同一批帧里，手中点绝对误差的平均值为 OMOMO 11.40 cm、BEHAVE 17.98 cm。共同平移手和物体并不会改变相对关系，所以任何只约束相对位置的先验都无法独自消除这种全局漂移。

作为诊断，用真实物体误差计算“沿预测双手连线的最优法向修正”（不可部署 oracle）后，一般物体帧平均误差最多从 13.03 降到 11.01 cm、24.01 降到 19.40 cm；切向误差仍然存在。法向误差只占三维平方误差约 22.5% / 30.1%。这说明仅凭一个平面标量无法解决主要三维误差。

## 三、补充实验设计

### 数据和基线

- OMOMO 测试：1,173 序列，196,385 个发布帧，74,617 个双手帧。缓存为 relabel_20260918_omomo 的 cur_hoi_p800/best，HP+VC+OT，已发布且经人体 refine 的物体轨迹。
- BEHAVE 测试：59 序列，86,094 个发布帧，26,964 个双手帧。缓存为 behave_hpsmooth_vcinit_20260922 的 v2_fixed_fusion/final，人体平滑参数 7、速度初始化差分 3。
- 两者均沿用各自缓存中的合成 IMU 噪声、online window=60、lookahead=10 和原初始化协议。新修正器只使用当前/过去发布信息，不增加 lookahead。
- 这些是明确标识的已有基线，不声称是仓库所有实验中最新或最优的模型；两数据集不是同一模型配方，不横向比较其绝对性能优劣。

### 训练与校准分开

- OMOMO 从原始训练集合按物体固定随机抽取 120 个有双手交互的序列，生成了相同 checkpoint 的预测缓存。75 个用于预测误差校准，45 个用于修正强度验证。
- BEHAVE 复用与测试 checkpoint SHA-256 完全相同的 32 个训练序列预测缓存，14 个用于误差校准，18 个用于强度验证。此数量较小，是重要限制。
- 训练共同偏移先验时，排除上述校准序列；剩余训练序列再按文件名哈希分成拟合与验证部分，测试序列不进入拟合或校准。
- 所有修正强度从 {0,0.10,0.25,0.50,1.0} 中根据训练侧验证的整体物体误差选择，附加 HOI 不恶化超过 1%、二阶差分不增大超过 10% 的保护条件。
- 这是多方案探索性重放，不是新的预注册独立测试。虽然强度不看测试答案，方法的多次比较仍要求后续独立验证。

### 共同偏移模型

    m=(h_L+h_R)/2
    c=R_obj^T(o-m)
    d=R_obj^T(h_R-h_L)

小模型使用 d、手间距、两个前臂相对物体的旋转、物体相对重力朝向，以及可选物体类别。它不使用预测物体位置来生成独立先验均值；修正阶段再与当前预测比较。

网络为两个 128 维隐藏层，类别 embedding 为 12 维；无类别对照统一为一个常量 token。每个训练序列最多取 200 个双手帧，训练 65 个 epoch，通过训练侧验证选择权重。双手差加入 2.5 cm 标准差噪声，旋转相关特征加入小扰动。该简单噪声不是完整上游预测误差模型，也不是时序学生网络。

当前 c 均值/协方差由训练交互标签直接统计，全部测试修正没有加载 mesh。它们是“可部署的交互统计先验”基线；本轮没有训练 mesh teacher，因此这些结果不能称为“mesh 蒸馏的收益”。

### 测试修正器能看到什么

允许：预测物体位置、预测掌点、预测接触概率、输入物体/人体 IMU、可选类别、过去的修正状态。

缓存中的 gt_obj_imu / gt_human_imu 是历史 dump 给输入 IMU 字段加的名称前缀，实际来自数据样本，保留了该样本的模拟 IMU 噪声；不是读取真实物体位置或真实骨架旋转。脚本不使用 gt_obj_rot 作为先验输入。

禁止：测试 mesh/点云、真实物体位置、真实手位置、真实接触标签。GT 只用于训练监督、校准目标和最终评分。新增测试会删除修正函数输入中的全部 GT 字段，确认输出不变。

## 四、修正方法和结果

比较了：零平面硬投影、训练分位数厚平面、类别法向均值、类别三维共同偏移协方差、学习的法向偏移、学习的三维偏移、预测输入残差 ridge、无类别学生、经验误差协方差，以及接触结束后保留因果修正状态的版本。

下表物体/HOI 为各序列均值再平均，单位 cm；双手物体误差是全部真实双手帧平均。强度均由训练侧选择，标“强制”的诊断除外。

|---|---:|---:|---:|---:|
| 原预测 | 13.316 | 12.975 | 24.689 | 24.037 |
| 直接硬投影，强制 100% | 13.691 | 13.814 | 24.765 | 23.919 |
| 类别均值+协方差软修正 | 13.323 | 12.991 | 24.407 | 23.220 |

“因果保留”指：只有预测双手接触可信时更新修正向量，接触间隙保留上次状态；其余版本逐步回到零修正。该实验仍是输出轨迹重放，没有把修正反馈进 OT、VC 或人体 refine，因此不等于闭环模型评测。

### 按训练侧选择，而不是挑测试最好结果

- 将全部候选按训练侧验证得分选择：OMOMO 选择无类别学生，测试整体误差几乎没有变化。即使类别学习版本的某些测试行有小幅改善，也没有足够实用收益，不能据此建议直接部署。
- BEHAVE 选择类别协方差+因果保留（强度 0.5），并非测试表中整体误差最低的学习版本。

BEHAVE 这一训练侧选择结果的更多指标：

| 指标 | 原预测 | 类别协方差+因果保留 |
|---|---:|---:|
| 整体物体误差（序列平均） | 24.689 cm | 24.403 cm |
| 整体 HOI（序列平均） | 18.687 cm | 18.052 cm |
| 双手帧物体误差 | 24.037 cm | 23.130 cm |
| 双手帧 HOI | 15.688 cm | 14.638 cm |
| 双手帧物体 P95 | 49.772 cm | 48.065 cm |
| 非双手帧物体误差 | 25.714 cm | 25.704 cm |
| 输出轨迹二阶差分 | 10.773 mm/frame² | 10.726 mm/frame² |

这里手位置完全不改，因此绝对手误差不变。二阶差分明确在发布轨迹上计算，不与仓库某些评估脚本在 raw 轨迹上记录的 obj_jitter 混淆。

按序列配对重采样 3,000 次，BEHAVE 整体物体误差变化的 95% bootstrap 区间约 [-0.615,-0.012] cm。它衡量当前缓存中序列间波动，不校正多重比较，也不代表跨实例/跨数据集置信区间。收益小，需要独立复验。

## 五、测试无 mesh 时，训练 mesh 应该怎么使用

推荐把 mesh 当成训练阶段的结构监督，学生网络只学习在测试观测下可推断的部分。

### 推荐目标：共同偏移的模式、均值和不确定性

    p(c,z | d, U_L, U_R, IMU历史, 接触概率, 可选类别)

z 是抓握部位/方式。输出一个或少数模式的均值和各向异性协方差；同时估计模式可信度与再抓握门控。

训练 mesh 可提供的额外监督：

1. 接触区域/部件模式：同一杆柄、对向面、同侧面、把手、椅背/椅座等，作为潜变量 z 的弱监督。
2. 哪个方向受约束：用局部法向、杆柄方向、接触点对歧义形成方向性精度/不确定性目标；对不可辨方向不强迫精确值。
3. 掌锚点到真实表面的偏置分布：为骨架锚点保留合理容差，避免把 canonical 掌点当作表面点。
4. 时间事件：接触部位是否稳定、滑移或切换，监督学生何时维持状态、何时重新估计。

不能直接声称教师能把未知测试几何“蒸馏出来”。当两个不同形状在现有 IMU/类别输入下不可区分时，学生只能输出更宽或多峰的条件分布。若只有粗类别，更不能沿用某个训练实例的精确主轴坐标或精确尺寸。

必须做三组消融来证明 mesh 独有的贡献：直接 GT c 监督；GT c + 类别；GT c + 训练 mesh 的模式/不确定性监督。因为 c 真值本来就存在，只加一个从同一标签回归 c 的 teacher 未必有新增信息。

### 推荐融合：带置信度的小幅残差，而不是直接替换

    c_hat = R_obj^T(o_hat - m_hat)
    delta_c = K (mu - c_hat)
    o_corrected = o_hat + R_obj delta_c

K 应根据先验不确定性、当前预测误差、双手可信度、手间距和接触阶段进行缩放。类别统计的简化版本可使用：

    K = alpha * P (P + Sigma_prior)^(-1)

本轮固定 P=(0.10 m)^2 I，再由训练侧校准 alpha。实际模型和先验共用上游 IMU/掌点，误差可能相关，因此这一式子只能作为需要校准的融合结构，不能假定是独立观测下的精确贝叶斯后验。

对于一般物体，薄平面可以作为对法向分量的弱正则；保留训练分布厚度，对木椅等长尾类别降低权重。对于杆柄，在训练时学习“横向窄、轴向宽”的偏移分布，但测试时不读取主轴 mesh。类别未知时让模型输出更大不确定性，不能自动启用强平面或强轴约束。

### 必须用预测输入训练修正器

如果学生只在真实掌点上学习 c，测试时真实掌点误差会引入分布差异。更合适的训练流程是冻结主模型，对训练集生成与测试相同的预测缓存，再训练学生。

要区分两种目标：

    c_rel_gt = R^T(o_gt - m_gt)          # 真实相对几何，改善相对 HOI
    c_eff_gt = R^T(o_gt - m_hat)         # 与预测掌点兼容的绝对物体修正目标

直接用 c_rel_gt 替换预测偏移会把手中点绝对误差传给物体。训练最终修正时应同时考虑真实物体位置和真实 HOI，或联合预测人体共同漂移与相对偏移，并明确权衡；不能用相对指标下降掩盖绝对位置变差。

本轮的预测残差 ridge 是这条路线的低容量对照，只有有限校准序列，收益很小；未完成大规模、严格 out-of-fold 的预测输入时序学生训练。

## 六、下一步优先级

1. BEHAVE 的类别协方差软修正可以作为便宜、可解释的实验基线。先在独立预测缓存复验，随后才考虑接入真正在线反馈。OMOMO 暂不改主模型。
2. 为所有训练序列建立 out-of-fold 或独立验证的预测输入，训练带不确定性的共同偏移时序学生。优先验证它是否能改善“已经符合平面但整体偏移”的情况。
3. 使用训练 mesh 给学生追加接触模式和各向异性不确定性监督，与完全无 mesh 的学生做同预算对照。
4. 做无类别、粗类别、已见实例类别、留一物体/新实例四个条件。当前结果只覆盖已见类别和类别隐藏两个条件，后者也不是未见物体泛化。
5. 同时检查物体绝对误差、手绝对误差、HOI、P95、接触切换跳变和非接触段误差。形状相对先验对共同全局平移不敏感，不能期望它独自修复全部根节点漂移。

## 七、验证、局限与产物

验证：

- 原始训练/测试文件集合互斥；校准预测序列全部属于原训练集。
- 校准与测试缓存的 HP/VC/OT checkpoint SHA-256 完全一致。
- 训练 raw IMU 解码旋转与保存 obj_rot 对齐。
- 四个单元测试通过：投影符号/切向不变、删除 GT 字段不影响修正、时间因果性、共同平移下观测特征不变。
- 实验均使用 WSL 原生 SAGE，每次运行前检查 GPU 显存。

局限：

- 原主模型可能使用既有测试协议进行 checkpoint 选择，这里没有重建整个研究项目的数据划分；只保证新增先验和强度不在测试上拟合。
- 原主模型训练见过本轮校准序列，因此存在模型误差分布偏乐观的问题；OMOMO 训练侧选择不能泛化到测试就是一个警示。必须继续用 out-of-fold 预测验证。
- BEHAVE 校准仅 32 个序列，分物体有的很少；不能过度解读类别特定效果。
- 重放保持原始网络输出与隐藏状态固定，因果保留只是后处理状态，不是重新运行闭环。
- 本轮没有训练 mesh 教师，关于其模式/协方差监督的建议属于待验证路线。
- 多项探索性比较只支持提出下一步，不支持宣称稳健大幅提升。
