# 物体形状能为双手交互提供什么相对位置先验

> 后续输入约束已明确：测试阶段没有 mesh，最多知道物体类别。本篇直接使用 mesh 主轴的实验仅作为几何诊断；可部署路线和不使用测试 mesh 的补充实验见 `docs/meshfree_bimanual_priors_experiments_20260930.md`。

日期：2026-09-29。范围：公开论文、当前 IMUHOI 代码，以及 process/IMUHOI++cano 下 OMOMO/BEHAVE 的全量双手接触几何。本次新增的是研究报告和诊断脚本，没有更改模型或启动训练。

## 研究结论

最值得采用的目标是：已知物体几何、物体朝向、双手相对位置和前臂朝向后，预测“物体参考点相对双手中点的多模态分布”，并用接触几何决定哪些方向有信息、哪些方向仍然不确定。

这比只按类别选择“等距平面或双手直线”更一般，也更贴近当前代码的 BimanualClosure。核心区别不是多加一个形状描述子，而是把形状变成对接触部位、相对偏移以及方向性不确定性的约束。

本次最有价值的新证据：OMOMO 五类杆柄物体，在“通过双手中点、方向来自物体自身主轴与物体朝向”的直线周围更集中。相比直接用双手连线，中位横向偏差从 7.35–19.03 cm 降至 3.94–5.53 cm，P90 为 7.08–9.85 cm。这验证了轴向与横向应采用不同强度的先验，但尚未证明能够改善预测输入下的模型性能。

## 一、先明确未知量：双手间距已知，真正缺的是共同偏移

以下是本报告的几何推导，不是某篇论文已有方法的复述。

设左右手掌锚点为 h_L、h_R，物体参考点为 o，物体坐标到世界坐标的旋转为 R。令：

    m = (h_L + h_R)/2
    d = R^T(h_R - h_L)
    c = R^T(o - m)

则物体坐标中的左右手掌锚点位置为：

    q_L = R^T(h_L-o) = -c-d/2
    q_R = R^T(h_R-o) = -c+d/2

给定手位置和 R，d 可直接计算；需要估计的是共同偏移 c。若当前两条“手→物体”的骨向量为 b_L、b_R，则应满足：

    b_L = c + d/2
    b_R = c - d/2
    b_L - b_R = d

双手闭环消除了两个骨向量之间的不一致，但不能独自确定共同偏移 c。形状先验真正应该补充的是 p(c | d, S, U_L, U_R, history)，其中 S 是带真实尺度、正确原点的几何，U 是前臂或手相对物体的朝向。

当前 model/rnn/bimanual_closure.py 已采用 o=m+Rc 的候选点形式，并使用双手位移、前臂相对朝向和 IMU 等特征。若后续实现，优先扩展这一已有表示；不是再建立一套不一致的坐标定义。是否启用该模块由具体运行配置决定，本报告没有把“代码中存在”视为“当前实验已启用”。

## 二、形状先验的六个层次

### 1. 接触表面与掌部偏置：给出可行域，而不必然给唯一位置

真实接触点 s_i 应位于物体表面，掌部骨架锚点 q_i 通常与它有偏移 e_i：

    q_i = s_i + e_i
    s_i ∈ surface(S)

e_i 取决于手部姿态、握法、接触方向以及 canonical 骨架的误差。因而不能把关节 22/23 硬吸附到 mesh 表面。ContactOpt 在手表面接触优化中也专门处理软组织容差；其手网格接触模型不能直接等同于 IMUHOI 的单个掌部骨架点 [R1]。

建议用接触部位条件下的有效掌部区域 A_i(S,z,U_i)，或学习 e_i 的均值和协方差。无完整手指观测时，先验应该更宽，不应该凭空补出确定的手指接触点。

### 2. 双接触区域配对：形状最直接提供的共同偏移先验

若候选有效掌部位置为 q_L∈A_L、q_R∈A_R，则只有满足 q_R-q_L≈d 的配对才与观测双手几何兼容。每对候选产生：

    c_candidate = -(q_L+q_R)/2

因此可构造：

    C(d,S) = { -(q_L+q_R)/2 : q_R-q_L≈d, q_L∈A_L, q_R∈A_R }

这可以理解为“符合当前两手位移的接触点对集合”。它包含了形状、尺寸、手的左右身份和部位关系，通常比两个独立手-物距离约束更有辨别力，但仍可能多解。

实现建议：对 mesh/部位预计算候选锚点和法向；先用点对位移筛选，再由前臂相对朝向、当前运动、上一时刻的接触部位给候选打分。不要只按 ||d|| 检索，完整三维 d 保留了相对物体的方向信息。不要把所有候选直接求平均，否则椅背、椅座等不同模式的平均值可能不对应任何真实握法。

这是一项针对 IMUHOI 的推导方案，并非已被本次实现验证的算法。ContactGen 说明接触建模可包含位置、手部部位和接触方向 [R3]；BimArt 说明分左右手的接触图及部件几何有助于双手交互生成 [R6]。两者支持所选表示方向，但不能替代本方案的实验。

### 3. 局部主轴与横截面：杆柄类最适合的便宜先验

设物体杆柄轴在物体坐标中方向为 a，||a||=1。分解：

    c_parallel = a^T c
    c_perp = (I-aa^T)c

对双手握在同一杆柄上的情形，优先约束 c_perp；c_parallel 可以处于较长区间，或具有多个抓握段模式。几何形式应接近“有厚度的管状可行域”，而不是 c_perp=0 的刚性直线。

物体 IMU 在完成传感器-物体安装朝向标定后，可给出轴在世界中的方向 Ra。使用手连线来估计这个方向，会把两手骨架误差和握持偏置引入轴方向。长杆参考点远离双手时，方向误差还可能带来较大的横向误差。本次数据检验支持改用物体轴方向，但未单独识别误差来源。

整体 PCA 只适合作为单一细长物体的初始轴。多腿支架、椅子、带偏置把手的工具应该用局部部件轴，不能给所有物体强行指定唯一“抓握主轴”。本次 OMOMO 五类整体细长程度足够高，整体 PCA 是有效且便宜的探针。

### 4. 对向面、边缘、把手：区域和厚度比物体中心更有用

- 箱子：若双手位于一对对向面，沿该面法向的物体位置被较强约束；面内滑动仍然可行。若握在同一面或相邻边，则切换到别的模式。
- 桌子/托盘：两手抓边缘时，桌面厚度和边缘位置比全物体等距更直接。整体桌子的中心还受桌腿和参考点定义影响。
- 椅子：椅背、座面、椅腿给出多个接触区域。需区分“同部件双手抓握”和“不同部件抓握”。
- 箱包/工具：把手与物体参考点之间的固定偏置有信息；不能把把手中心当作整个物体中心。
- 细长盒子/瑜伽垫：可能双手抱在两侧，也可能沿长度方向握持，因此“物体细长”本身不能确定双手连线方向。

以上是对具体抓握条件的几何推导，不应被写成所有帧成立的类别规则。BimArt 使用部件感知表示并保留左右手接触信息，能够提供方法上的参考，但其主要任务是给定关节物体轨迹生成手动作 [R6]。

### 5. 对称性与可观测性：必须明确哪些方向无法由形状确定

理想球体是有用的反例。假设两手位置就是真实接触点、参考点是半径 r 的球心，则：

    ||c-d/2||² = r²
    ||c+d/2||² = r²
    => c·d = 0
    => ||c||² = r²-||d||²/4

球心必须位于等距平面中，但一般仍在一个圆周上，不能唯一定位。只有两接触点恰为直径两端等特殊情形，圆退化为一点。人体掌部偏置会进一步放宽这个约束。

对无限圆柱，同一抓握形态可以沿轴向平移，因此形状单独不给轴向位置；有限长度只给区间，局部把手/挡块才能进一步定位。对称盒子也可能存在多个等价握法。

局部线性化还有一个直接结论：若每只手只提供一个标量表面距离残差，则平移信息矩阵为 H≈Σ_i w_i n_i n_i^T。两手只给两项，rank(H)≤2；若法向平行或相反，rank 可能仅为 1。不能把“两手都在表面上”误读成“三维位置已完全确定”。这是对“仅两个表面距离残差”的局部秩判断，不包括已知接触对应、多个手表面点或时序动力学带来的额外信息。

建议把低信息方向保留为大协方差。G-HOP 表明联合手-物分布可以作为生成/重建先验 [R4]，CHOIR（WACV 2025）用连续接触分布提供了紧凑表示 [R5]；这些方法不能消除问题本身的物理不可辨识性。

### 6. 接触持续性与抓握切换：时序条件缩小多解

在同一刚体、固定无滑移接触期间，对应的物体局部接触区域应相对稳定；滑动、转动抓握、松手及再抓握应允许区域改变。时序应该保持“接触部位假设”，而不是无限期锁死某一帧的骨向量。

TOCH 在物体坐标中建模手-物对应及其时间变化 [R2]。CHOIR（2026 年的另一篇同名工作）采用动态更新的接触约束做联合优化 [R7]。从中可借鉴的是时序对应和可更新约束；它们的视觉输入及手部信息与本项目不同。

## 三、这次新增的本地检验

### 3.1 物体自身主轴显著改善杆柄类的几何描述

重新读取全量 5,882 个 OMOMO 和 299 个 BEHAVE 序列，筛出 513,577 个有效双手交互帧，数量与前两轮完全一致。旋转矩阵正交性通过检查。每个物体本地网格固定种子采样 20,000 表面点，计算主轴 a。

比较两条直线，均通过双手中点 m：

    L_hand: m + t(h_R-h_L)
    L_object_axis: m + t R a

表中是物体参考点 o 到直线的距离，不是预测误差。

| OMOMO 物体 | 双手连线距离中位 cm | 物体轴方向直线距离中位 cm | 后者 P90 cm |
|---|---:|---:|---:|
| mop | 19.03 | 5.17 | 9.85 |
| vacuum | 17.84 | 3.94 | 8.59 |
| clothesstand | 10.58 | 5.41 | 9.45 |
| tripod | 10.06 | 4.51 | 7.08 |
| floorlamp | 7.35 | 5.53 | 9.30 |

若用训练集标定横向均值而非强制为零，测试集横向残差中位数为：拖把 4.17、吸尘器 4.96、衣架 5.08、三脚架 4.60、落地灯 5.14 cm。对应 10 cm 内的测试帧占比为 97.57%、94.61%、93.48%、98.89%、99.69%。

但这些物体的全量轴向偏移标准差依次为 9.04、13.91、24.49、20.10、18.17 cm。横向集中并不意味着完整三维偏移容易预测，仍需定位沿杆身的抓握段。

限制：此处用真实物体朝向和真实手掌锚点；真实系统中两者的误差及安装标定误差会扩大管径。对 BEHAVE 的瑜伽垫，当前原始划分没有双手交互测试帧，因此不报告该类的留出测试结果；CSV 中相应指标留空。

### 3.2 双手位移不能完全决定共同偏移；前臂朝向有额外信息

做了一个轻量、训练/测试分开的检索诊断：每个物体最多 12,000 个训练帧作为支持，测试最多 4,000 帧；20-NN 输出训练邻居 c 的均值。比较同一测试子集的三种条件：

1. 物体身份条件的固定 c 均值。
2. 物体身份 + 真实 d。
3. 物体身份 + 真实 d + 相对物体的真实左右前臂旋转。

旋转特征使用每个旋转矩阵前两列，共 12 维，距离度量中乘 0.1 m。该权重没有用测试集调优。其目的是检查观测是否有信息，不是提出最佳检索系统。

四个例子（共同偏移 c 的平均三维误差，cm）：

| OMOMO 物体 | 固定物体均值 | 双手 d 检索 | d + 前臂朝向检索 |
|---|---:|---:|---:|
| floorlamp | 14.55 | 13.27 | 10.30 |
| vacuum | 14.02 | 11.62 | 10.23 |
| monitor | 10.55 | 8.39 | 6.94 |
| smalltable | 10.59 | 8.40 | 6.25 |

OMOMO 15 类均出现了加入前臂特征后的误差下降；BEHAVE 并不一致，例如有类别变差，说明该简单度量、训练覆盖及模式选择都仍有问题。对于相近 d 的 20 个训练邻居，共同偏移仍存在数厘米到十余厘米的分散，支持用分布而不是唯一查表值。

限制：这是已见物体身份下、真实输入条件下的诊断，不是形状跨物体泛化，不是完整物体轨迹评估，也不是最优可达误差的上界。数据沿用现有 train/test 划分，没有保证跨动作/跨主体完全独立。当前实验没有加入预测噪声，也未使用完整序列历史。

## 五、针对当前仓库，我建议的实现路线

### 第一步：先做物体轴的软先验，验证最明确的新信号

利用已有可选 BimanualClosure 的 c 表示，对具备可靠杆柄轴的物体建立：

    c ~ sum_z pi_z N(mu_z, Sigma_z)
    Sigma_z = sigma_parallel,z² aa^T + P_perp Sigma_perp,z P_perp
    P_perp = I-aa^T

这里 z 可以是上段/中段/下段抓握区域，也可以是其他从训练集识别的模式。公式用于强调方向性和多模式；实际实现可采用沿轴的一维混合分布与横截面的二维分布，避免冗余参数。

直接预测 mu、协方差及模式权重；横向均值不应固定为零。对物体朝向或接触置信度不足的帧增大不确定性，并允许已有 IMU/时序分支占更高权重。不要按物体名永久启用一个强约束，应检查部件轴可信度、是否双手接触、是否对应当前握持部件。

### 第二步：接触区域配对先验，覆盖箱子、桌椅、把手

离线从 mesh 提取候选区域、法向、局部厚度/曲率及有效掌部偏置。在线由 d、两前臂相对物体朝向和历史模式选择候选配对，得到少量 c 候选及其协方差。

可先用条件混合高斯或候选排序做基线，暂不需要一个大型 diffusion。只有明确观察到小模型无法表示的复杂多峰结构，且延迟预算允许时，再考虑更复杂生成模型。该取舍是基于本项目输入维度和当前可用证据的工程判断。

### 第三步：联合修正手和物体，并按可观测方向分配权重

若只修正物体，可能把手的误差传给物体；若只修正手以减小 HOI，也可能掩盖绝对手误差。联合目标应包含 IMU/运动预测残差、形状/接触残差和时间一致性，并按各自不确定性分配修正量。

形状约束对手和物体共同的全局平移不敏感，因此不能解决全部绝对漂移。应分别汇报物体绝对误差、手绝对误差、相对 HOI 误差及抖动。

仓库已有 docs/cano_ot_v3_vs_current_and_mesh_20260908.md 记录：在当时指定缓存和配置下，简单骨向量硬投影到表面使 obj/HOI 变差；逐帧把手拉向物体改善 HOI 却使绝对掌部误差变差。这里将其作为避免重复方案的历史证据，不把旧缓存数字当成当前基线。本次新增的物体轴先验不同于简单最近表面投影，其实际收益仍需重放验证。

## 六、实验顺序与判定条件

建议按成本从低到高推进：

1. 在固定在线预测缓存中，对五类杆柄物体加入各向异性软轴约束，和当前模型、平面约束、双手直线约束比较；先不重训主模型。
2. 做 GT 手/预测手 × GT 接触/预测接触 的对照，另加物体朝向与安装角度噪声，分离几何潜力和输入误差。
3. 针对长杆手间距小、参考点远离双手、接触 onset、再抓握和滑移分组，检查尾部与抖动。
4. 在“仅物体身份”“全局形状”“局部部件/候选配对”之间消融。使用留一物体测试及跨数据集同类物体验证形状泛化，避免仅记住 15/18 个身份。
5. 若重放显示独立收益，再训练 p(c,z|d,S,U,history) 并校准预测不确定性；以 held-out coverage 和误差方向分解验证协方差，不只看平均误差。

必须同时满足：相对误差改善不是通过恶化绝对手/物误差获得；尾部没有明显恶化；接触失误时不会突然吸附到错误部件；模式切换不产生位置跳变。现有诊断尚未完成这些模型层面的验证。
