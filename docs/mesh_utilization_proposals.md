## 0. 结论先行

| 问题 | 答案 |
|---|---|
| mesh 对当前流水线**独有**的信息是什么 | 不是形状描述子（15 个物体，IMU 信号已能推出物体身份），而是 (a) **能把二值接触标签变成可测的接触几何**（接触点在表面哪里、掌根到接触点的偏置、抓握切换事件、物体是否被地面支撑），(b) 测试期若已知 mesh，可提供**地面非穿透**这类与人体误差不相关的硬约束 |
| 物体分支上"骨向量落在表面上"这条几何约束值多少 | 几乎为零：**OT-v3 的骨向量尖端离表面已经和真值一样近**（中位 2.9 vs 真值 2.6 cm）[replay]；硬投影 GT 骨向量反而变差（8.55 → 9.09）[oracle]；软投影只有 −0.17 obj / −0.32 HOI [replay] |
| "接触 onset 时把手吸附到物体表面"（以物体为手的 landmark）值多少 | **朴素做法为负**：全段重放 obj 13.92 → 15.05、HOI 9.46 → 11.51 [replay]。原因：onset 处手误差**主要沿表面切向**（预测掌根离预测表面中位 5.6–7.5 cm，真值本就 4 cm），表面法向约束修不了；且 82% 的预测 onset 才与真值对上 |
| 唯一实测为正、且便宜的测试期用法 | **地面非穿透 → 人-物联合竖直修正**：published obj **14.20 → 12.98（−1.21）**，HOI 不变（同步平移手），接触帧掌根误差 13.86 → 13.22 [replay]，用固定地面高度即可（canonical 数据里地面高度按构造已知） |
| 训练期专用（测试期不给 mesh）的价值上限 | 只能改善标签和辅助损失，**碰不到 7–8 cm 的手部漂移**（观测受限，不是标签受限）。预期合计 ≤1 cm，主要在尾部（再抓握、椅子类） |
| lb_vq_diffusion 为什么无效 | 它从 mesh 里提取的是 BPS 形状描述子（≈物体身份，冗余），预测的是每窗骨长分位数（标量，MAE 6.6 cm，而 head 自己能从 `‖p_prev − h‖` 算出长度），以 6 维常量广播注入（易被忽略）。三处都没有新信息 |
| 需要你决定的事 | **测试期是否允许已知物体 mesh / 身份**（把 IMU 贴到哪个物体上是已知的；demo 已接收 `--object-mesh`）。允许 → 做方案 A + B + C；不允许 → 只有方案 B 和 A 的训练期变体，预期合计 ≤1 cm |

一句话：**mesh 的几何约束在物体分支上是冗余的（网络已学会），它真正能加的是"接触的几何标签"与"物-地约束反推人体竖直误差"。若目标是显著降低 HOI/obj 误差，最短路径仍是用物体 IMU 约束臂链（handoff 方向 1），mesh 在其中只提供杠杆臂的接触点标签。**

## 1. 第一性原理：误差预算里 mesh 能碰哪一项

handoff §6 的分解（预测输入下）：手部 ≈ 8 cm、接触 ≈ 2.5、锚点继承 ≈ 0.5、FK 假设本身 ≈ 5（真值手下），
其中 FK 假设的 5 cm 里有 3 cm 是"锚点选得不好"（L0 6.41 → L1 3.45）、剩下是握点滑移与腕部不可观测。

mesh 是物体坐标系下的表面流形 S 加法向。它能提供的约束/信息只有四类：

| 编号 | 信息 | 约束的未知量 | 训练期可用 | 测试期需要 mesh |
|---|---|---|---|---|
| M1 | 接触点 ∈ S（掌根离 S 有 ~4 cm 解剖偏置） | 骨向量 c 的 1 个自由度（法向） | 是 | 是 |
| M2 | 表面法向 / 内外侧 | 手在物体哪一侧 | 是 | 是 |
| M3 | 支撑几何：最低顶点高度、地面非穿透 | 物体竖直坐标；被握时同时约束手的竖直坐标 | 是 | 是 |
| M4 | 把接触标签变成几何量：接触点轨迹 q(t)、掌根→接触点偏置 v、滑移/再抓握事件、支撑状态 | 锁存门控、结构化残差的 pivot、静止门控 | **是（这是训练期唯一独有的）** | 否 |

对照误差预算：M1/M2 作用在骨向量上，而骨向量误差是**补偿量**——head 学到的是 `R_objᵀ(p_prev − h)`，
把手的误差吸收进骨向量里，物体位置反而是对的；"修正"一个补偿量只会把手的误差还给物体（§3.2 的重放证实）。
M3 与手部误差**不相关**，所以能独立起作用（§3.4）。M4 只改善标签，改善的是 handoff 已识别的两个小项（再抓握、pivot），
碰不到手部漂移。

## 2. lb_vq_diffusion 的诊断

`model/rnn/lb_vq_diffusion.py`：特权 VQ 编码器看 (预测姿态, 接触, GT 物体位姿, BPS mesh 描述子) → 重建每窗左右手骨长 [q10,q50,q90]；
观测条件扩散从 (HP/VC 输出, 物体 IMU) 预测冻结的 VQ latent；结果 6 维分位数广播进 OT head。
`outputs/IMUHOI_RNN_2/lb_vq_diffusion_all_07241411/metrics.jsonl` 最终 `sample_quantile_mae_cm = 6.6`。

三处没有新信息：
1. **输入侧**：BPS(128 基点) 描述子对 15 个物体退化为 one-hot 身份；身份从 IMU 信号统计（骨长、转动模式）已可推出。
2. **输出侧**：骨长只是骨向量 (3 维) 的模，且 head 在有状态反馈时能直接算 `‖p_prev − h‖`；
   本文 §3.1 的 GT 统计显示骨长分布本身跨序列 range 0.3–1.0 m（`outputs/analysis/contact_bone_lengths_OMOMO_bps_test/analysis.md`），
   每窗分位数对逐帧骨向量的约束很弱。
3. **注入侧**：6 维常量拼进 LSTM 输入，与已有的反馈特征冗余，训练时可被忽略。

更根本的是：训练期专用的先验只能加"从观测可推断"的东西，而骨长基本可推断、手部误差不可推断。

读法：
- 掌根锚点离表面**中位 3–5.5 cm、p90 7–10 cm**，"骨向量尖端在表面上"是一条 ±4 cm 的软约束；

### 3.3 以物体表面为手的 landmark [replay]

在每个预测（滞回）onset，把 OT 消费的掌根拉到"上一帧发布物体位姿下 mesh 表面最近点 + 3 cm"：

| onset 子集 | 数量 | 掌根误差 预测 → 吸附后 | 改善比例 | onset 前物体误差 | 预测掌根→预测表面距离 q50 |
|---|---|---|---|---|---|
| 全部预测 onset | 2025 | 10.36 → **11.72（变差）** | 63% | 5.98 | 6.7 |
| 首个 onset | 1015 | 8.61 → 9.12 | 65% | 2.57 | 5.9 |
| 后续 onset | 1010 | 12.13 → 14.33 | 60% | 9.40 | 7.5 |
| 与 GT onset 对上（±5 帧） | 1659 | 9.92 → 9.20 | 69% | 4.73 | 6.0 |
| 首个且对上 | 875 | 8.55 → **7.64** | 69% | 2.21 | 5.6 |

整段常量修正（骨向量同步反补偿、HOI 用修正后的手）：raw obj 13.92 → **15.05**、HOI 9.46 → **11.51**、接触帧掌根 13.5 → 14.4。

三个原因，都是结构性的：
1. **手误差主要沿表面切向**：预测掌根离预测表面只有 5.6–7.5 cm（真值 4 cm），法向只剩 1–2 cm 可修，切向 8 cm 修不了；
2. **18% 的预测 onset 不是真 onset**（假接触），吸附把手拉错；
3. 后续 onset 的物体位置本身已有 9.4 cm 误差，landmark 不可信。

最好的子集（首个且对上）也只从 8.55 到 7.64。handoff §9 的"物体当根节点 landmark"（hoi 11.4 → 7.4）用的是物体**中心**而非表面、
且拉的是整个人体，与本实验不可比；本实验说明**几何吸附本身不是那条路**。要修切向误差必须知道"握在物体哪个部位"——见 §3.5。

### 3.4 地面支撑 / 非穿透 [oracle + replay]

GT [oracle, canonical]：物体静止帧最低顶点高度中位 −2.7 cm（q10 −7.8、q90 +8.0），
静止帧中 17% 在地面 ±2 cm 内、60% 在 ±5 cm 内；运动帧 13% / 37%（拖地：mop/vacuum/suitcase/椅子）。
按物体有系统偏置（floorlamp +3.0、tripod +3.2、suitcase +4.2、smalltable −4.6）——OMOMO 的物体拟合/缩放本身有厘米级误差。

## 4. 方案（按证据强度排序）

### A. 地面非穿透 → 人-物联合竖直修正 ★★★（实测 −1.2 obj，HOI 不变；需要测试期 mesh）

**机制**：`y_min(t) = min_v [R_obj(t)·s·V + p(t)]_y`（V 为 canonical 顶点，`obj_points_canonical` 已在 data_dict 里，
但 256 个采样点估最低点会偏高 1–2 cm，建议用 `object_geo_root` 全 mesh 或预存 2k 顶点）。
若 `y_min < floor − margin`，`Δy = floor − margin − y_min`，同时加到 published 物体和 refined 手（以及臂链 IK 或至少 `pred_palm_glb_pos`）。

**落点**：`eval_IMUHOI.py::_build_published_object_trans` 之后、`hoi_contact_residual` 之前，作为显式 runtime 步骤；
不回灌 HP/VC/OT。地面常量在训练集标定（canonical 下应接近 0 到 −2 cm；按物体偏置可选，替代收益仅 −0.1）。

**训练期变体（若测试期不许用 mesh）**：在 OT 的 refine 头训练里加可微非穿透 hinge
`max(0, floor − y_min(pred_obj, R_obj))`，同时把 published 物体重新由 refined 手 FK 得到——让 refine 头学会"这个物体这么低时抬臂"。
这是学出来的先验而非硬约束，预期明显小于 −1.2，需实验。

**风险**：真实 IMU 的 R_obj 漂移会让最低点估计漂；OMOMO 里 GT 自身穿地（q10 −5.6 cm）意味着上限就是本表数字，不会更多。

### B. mesh 派生的接触几何标签 → 监督 v3 的软锁存门控与 pivot ★★（训练期专用；预期 ≤1 cm，主要在尾部）

**预处理新增字段**（`process/preprocess.py::precompute_sequence_features`，schema 升级）：
- `lhand_contact_point / rhand_contact_point [T,3]`：GT 接触帧上掌根在 canonical mesh 上的最近表面点 q(t)（用全 mesh，不要 256 点）；
- `*_contact_offset_forearm [T,3]`：`R_forearmᵀ(q_world − palm)`——结构化残差 (handoff 式 5) 的 pivot v 的**直接测量**，
  中位 |v| ≈ 3 cm、去掉均值后残差中位 2 cm（§3.1）；
- `*_contact_normal [T,3]`、`*_contact_surface_dist [T]`；
- `*_regrasp_event [T]`：q(t) 在表面上 5 帧内跳变 >5 cm、或左右手交换 → 事件标签
  （注意：这一项不用 mesh 也能从骨向量跳变得到，mesh 只是让它对掌根偏置更鲁棒）；
- `obj_supported [T]`：mesh 最低点在地面 ±2 cm 内（比"静止"更物理的静止门控标签）。

**用法**：
1. v3 门控 α 的显式监督：onset/再抓握事件处 α→1、稳定持握处 α→gate_floor（现在 α 只经末端损失间接学习；handoff §8 显示 head 学到的 α 均值 0.15 是合理的，但**同段内再抓握**仍失败，序列 444 类）。
2. 恢复 v3a 的结构化残差但**有监督**：`c(t) = a − (M(t) − I)·v`，M 用可观测的 `R_objᵀR_forearm` swing（已在 v3 输入里），
   v 由 head 输出并用 `contact_offset_forearm` 监督；v3a 失败的三条原因里"pivot 不可辨识"由此消除，另两条 v3b 已解决。
   上限：L0→L3 = 6.41 → 2.27（真值手），预测手下被 handoff 估为 1–2 cm。
3. `obj_supported` 作为 VC-v4 的辅助头（与 endpoint/anticipation 头同构），把静止硬门控从规则升级为学习（handoff 方向 3，上限 −0.6）。

**验证顺序**：先用 `scripts/replay_bone_variants.py` 风格重放"GT 再抓握事件处重置锁存"，看尾部收益；再训练。

### C. 带解剖偏置的软表面项 ★（测试期 mesh；实测 −0.2 obj / −0.3 HOI）

把 `d(t) = dist_S(−b(t) + R_forearmᵀ-偏置)` 作为 v3 head 的每帧输入特征（连同最近点方向）并加 hinge 损失 `max(0, d − 3 cm)`；
不要硬投影。收益小但稳定，实现成本低（需要测试期最近点查询：预存 60k 表面采样 + cdist，或 OMOMO 自带的 `rest_object_sdf_256_npy_files` SDF 网格做三线性查表，可微）。

### D. 离散抓握假设锁存（多假设滤波） ✗（探针为负，不建议作为主机制）

设想是把 v3 head 的骨向量参数化改为"K 个 mesh 锚点上的分布 + 小残差"，软锁存变为离散假设的贝叶斯滤波（再抓握 = 假设切换）。
§3.5 的两个探针都不支持：各向同性噪声下锚点去噪不优于表面投影；上下文预测抓握区域的尖端误差（17.7）远差于冻结首帧骨向量（7.4）。
剩余的可能用法只有一种：在 B.1 检测到再抓握、且旧骨向量已不可信时，用"上下文 + 上一骨向量"的锚点后验做重置初值——收益局限于细长物体的尾部，优先级最低。

### 不建议（已实测）
| 想法 | 结果 |
|---|---|
| 骨向量尖端硬投影到表面 | GT L0 8.55 → 9.09；重放 −0.02 |
| onset 处把手吸附到表面（几何 landmark） | 全段 obj +1.1、HOI +2.0 |
| 静止帧吸附到地面（规则/p_move） | +0.23 / +0.25 |
| BPS 形状描述子 / 每窗骨长分位先验 | 已做（lb_vq），无效，原因见 §2 |
| 各向同性去噪意义上的锚点先验 | 不优于表面投影（§3.5） |
| 从可观测上下文预测抓握区域（离散锚点） | 尖端误差 17.7 vs 冻结首帧 7.4（§3.5） |

## 5. 建议的实验顺序与 go/no-go

1. **零训练（1 天）**：在 canonical 流水线的 publisher 后实现方案 A（人-物联合竖直修正），先在训练集标定地面常量，再跑正式 `eval_batch_online.py`。
   go：published obj 下降 ≥0.8 且 HOI/MPJPE 不变差。本文 −1.2 是旧 schema 缓存上的数字，canonical 下需重测。
2. **预处理（1–2 天）**：方案 B 的接触几何字段 + 单元测试（`test/test_preprocess_omomo_canonical.py` 同款）。
3. **重放验证（半天）**：GT 再抓握事件重置锁存的重放；若尾部（>25 cm 序列占比、whitechair/woodchair）无改善，B.1 降级。
4. **一次 OT 训练（上游冻结）**：v3 + B.1 门控监督 + B.2 有监督 pivot + C 软表面项，与同代码同数据的 v3 基线比。
   go：obj/HOI 任一 ≥0.3 且另一不变差；按物体 15 类不劣化。
5. D 已由探针否决，不做。
6. **真正动手部误差的方向不在 mesh 上**：接触条件化的臂链精化（物体 IMU 作第七传感器），mesh 只提供 B 的接触点标签作杠杆臂，以及 A 的竖直证据。
