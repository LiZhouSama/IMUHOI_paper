# 双手位置先验补充训练实验（2026-10-01）

> 范围更正：这里的“完成 24 次训练”仅指冻结底座上的轻量修正模块实验。每个 epoch 固定 32 个随机 batch，不是全数据遍历；没有完成 HP/VC/OT 重训、完整 mesh 教师蒸馏或收敛性证明。实际步数和耗时见 `docs/meshfree_bimanual_training_execution_audit_20261001.md`。

完成 24 次训练：4 个版本 × 3 个随机种子 × OMOMO/BEHAVE 两个数据集。另完成统计先验对照、方向性方差融合对照，以及训练期 mesh 辅助任务验证。测试时不使用 mesh、点云、真实手/物位置或真实接触标签来生成修正。

## 有效方法与实际幅度

- **OMOMO：小型预测输入残差学生有稳定但很小的收益。** 校准侧选择逐帧类别学生＋方向性方差融合，整体物体误差 13.233→13.142 cm，约 0.92 mm；双手帧 13.037→12.824 cm。HOI 基本不变（9.423→9.427 cm），抖动略降。时序类别学生也有效，但没有明显超过逐帧版本。
- **BEHAVE：类别统计软修正仍是最有成本优势的对照。** 整体物体误差 24.688→24.355 cm，双手帧 24.127→23.162 cm，整体 HOI 18.924→18.196 cm；二阶抖动增加约 2.67%，必须同时披露。
- **预测输入时序类别学生在 BEHAVE 上有小幅稳定收益。** 结合方向性方差融合，整体物体误差 24.688→24.415 cm，双手帧 24.127→23.480 cm，整体 HOI 18.924→18.655 cm；抖动增加约 1.22%。若更在意平滑性，它提供了另一项折中。
- **本轮 mesh 接触／表面辅助监督没有稳定的额外位置收益。** BEHAVE 加 mesh 相比不加 mesh 的整体物体误差只低约 0.004 cm，配对组 bootstrap 区间跨零；OMOMO 反而微弱变差。不能据此声称所有训练期 mesh 方法无效。

建议保留简单统计软先验和轻量预测输入学生作为实验基线。OMOMO 的收益不足 1 mm，不值得为此大改主模型；这版 mesh 辅助头不应作为有效创新点。没有替换项目默认模型。

## 数据、训练与验证协议

- OMOMO 原训练集 4,705 序列，802,833 发布帧；按主体—物体组划为 3,296 拟合、712 验证、697 校准。组数分别 73/15/15。原测试 1,173 序列，196,385 发布帧，74,617 双手帧。
- BEHAVE 原训练集 236 序列，351,317 发布帧；分为 143 拟合、43 验证、50 校准，组数 60/18/15。原测试 59 序列，86,094 发布帧，26,964 双手帧。
- 重新生成两套数据的训练／测试预测缓存。OMOMO 使用 cur_hoi_p800/best；BEHAVE 使用 v2_fixed_fusion/final、人体平滑半宽 7、速度初始化差分 3。每对缓存使用相同 checkpoint 和当前代码。数值应与本轮重新生成的基线比较，不拼接上一轮旧缓存分数。
- 固定原在线协议：window 60、lookahead 10、batch 32、seed 42、模拟 IMU 噪声。学生不增加 lookahead，保留原始初始化帧。
- 底座 HP/VC/OT 冻结。逐帧与时序版本参数约 3.5 万；时序模型为单向 GRU64。每次最多 60 epoch、每 epoch 32 个窗口 batch，batch 48、窗口 128 帧、内部窗口前 24 帧作为 burn-in。随机种子为 1001/1002/1003。
- 验证组选择 checkpoint；另一组校准集选择增益、方差权重和接触结束后是否保留修正。增益为 0/0.1/0.25/0.5/0.75/1。校准保护条件：HOI 增加不超过 0.02 cm，二阶差分不增加超过 3%，双手 P95 不增加超过 0.2 cm。测试不用于选择这些参数。
- 初始监督主要是预测输入下的物体绝对误差，同时保留 HOI、几何共同偏移、平滑、残差正则和误差方差监督。所有训练输入均来自原模型预测或 IMU 观测；真实位置只作为训练目标。
- mesh 辅助版本额外预测左右接触区域、附近表面点和法向；每个训练 mesh 固定采样 12,000 点，8 个 KMeans 区域。使用真实训练姿态生成监督，按掌点到表面的距离衰减权重。测试预处理不生成 surface_target / patch_target，推理接口也没有 mesh 参数。
- 标量方差融合与方向性融合单独比较。后者在观测物体系各轴按 0.01/(0.01+预测方差) 缩放，然后回到世界坐标；同样只在校准组选择融合强度。

## mesh 辅助任务是否确实学到了内容

在训练划分内部的独立验证组上比较类别常量与 mesh 辅助学生；置信度加权统计，仅用于诊断辅助任务，不参与测试选参。

| 数据集 | 方法 | 接触区域准确率 | 表面点误差 cm | 法向余弦相似度 |
|---|---|---:|---:|---:|
| OMOMO | 类别／左右手常量 | 20.05% | 21.96 | 0.019 |
| OMOMO | mesh 辅助学生，3 种子均值 | 33.72% | 7.68 | 0.530 |
| BEHAVE | 类别／左右手常量 | 24.29% | 25.88 | 0.095 |
| BEHAVE | mesh 辅助学生，3 种子均值 | 27.81% | 12.76 | 0.529 |

辅助任务的目标确实被学习到，但这些改善没有稳定转化为额外的物体位置收益。它支持停止把这版辅助头视为有效增益，不能证明更完整的接触模式或 mesh 教师方案都无效。

## 验证与局限

- 11 项单元测试通过：时序前缀因果性、分块状态一致性、无类别隔离、训练辅助头与推理输出隔离、有限梯度、删除 GT 字段不改变修正、物体坐标系方向性方差、初始化与增益线性等。
- 原数据、主模型默认配置和默认评测行为未修改。新增学生模块未自动接入项目主推理路径。
- 这是冻结发布轨迹上的学生训练和因果后处理验证，尚未把修正反馈进 OT/VC/人体 refine 的闭环中。不能把结果当成闭环运行已经验证。
- 上游 checkpoint 原先训练见过原训练集；本轮学生拥有组隔离的验证和校准、原测试留出，但不是整条流水线的 out-of-fold 预测训练。
- 使用原数据划分和已见物体类别；没有验证同类新物体、未知安装朝向或真实硬件 IMU。
- 网格只作为训练辅助标签，未实现大型 mesh 教师或多峰生成模型。本轮结果只适用于这次实际实现的方案。
- 所有实验使用 WSL 原生 SAGE，并在每次启动前检查 GPU 显存。运行日志、选择轨迹、checkpoint 和逐序列结果均保留。
